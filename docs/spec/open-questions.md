# Open Questions

## Answered

| # | Question | Answer |
|---|---|---|
| 1 | What is Strata? | An open-source local inference engine that exposes an **OpenAI/Anthropic-compatible local API**. It has a **Strata** preset using the OpenAI-compatible adapter; its default port isn't confirmed, so the preset auto-probes common ports and the address can be edited. |
| 2 | Starter world? | Not required. Ship an **example world template** with Milestone 2's lorebooks. |
| 3 | After death | New adventurer in the same world. **Inheritance only through children:** if the character had children, the player can continue as one of them ([03](03-characters-and-cards.md#when-a-character-dies)). |
| 4 | Skill progression | **Use only** (OSRS-style). Level-up points became **Renown**, which affects how people treat the character, grows slowly and comes from the story ([04](04-rules-system.md#renown)). |
| 5 | Sex modifiers | **Realistic by default:** men physically strong but socially must prove themselves; women socially advantaged, physically fragile, magic-leaning, and more often captured than killed by human enemies. Toggle to Off per campaign ([04](04-rules-system.md#attribute-caps)). |
| 6 | Art? | Placeholders for now, made as good as possible; replaceable through the theme system. |

| 7 | Phone outside the house? | **Home Wi-Fi, plus a link for a tunnel.** Home Wi-Fi is how the artist plays; a Cloudflare (or Tailscale) tunnel link, paired with the same key, is how the game is tested away from home (0.5.0). |
